# Security Policy

## Supported versions

Security fixes are provided for the latest published release. Users should
upgrade to the latest release before reporting an issue against an older version.

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public issues or pull
requests.

Use GitHub's private vulnerability reporting for this repository (the
**Security** tab → **Report a vulnerability**) to contact the maintainers
confidentially. Include the affected version or commit, the impact, and steps
to reproduce where possible.

If private vulnerability reporting is unavailable, contact the repository
maintainer through GitHub rather than publishing exploit details.
